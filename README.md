## Структура

- `index.html` — экран выбора версии
- `assets/config.js` — **единый конфиг**: онлайн-запись и контакты (адрес, телефон, часы, WhatsApp, Instagram)
- `assets/booking.js` — запись: демо или виджет Altegio / YCLIENTS, или любая ссылка
- `assets/site.js` — подставляет контакты из конфига в страницы (версии 05–07)
- `assets/switcher.js` — панель переключения версий
- `assets/icons/`, `*/manifest.webmanifest` — иконки и манифесты для «На экран Домой»

## Онлайн-запись через Altegio

1. В Altegio: **Онлайн-запись → Виджеты/Формы** → создать форму. Ссылка формы вида `https://b123456.alteg.io` → номер `123456`.
2. ID филиала — из ссылки `…/company/312313/…` → `312313`.
3. ID мастеров — в карточке сотрудника (или из ссылки `?o=m2131037` → `2131037`).
4. В `assets/config.js`:

```js
booking: {
  provider: "altegio",
  widgetId: "123456",
  companyId: "312313",
  staff: { dima: "2131037", kirill: "…", b3: "…" }
}
```

После этого **все** кнопки «Записаться» во всех версиях открывают виджет Altegio поверх сайта
(класс `ms_booking` + `data-url`), а кнопки у конкретного мастера сразу открывают его расписание.
YCLIENTS — то же самое с `provider: "yclients"`. Для WhatsApp/Fresha/Calendly — `provider: "link"` и `link: "https://…"`.

## На телефоне как приложение

Safari → «Поделиться» → «На экран „Домой“». Каждая версия ставится со своей иконкой
(`start_url` = эта версия) и открывается без панели браузера.

«GRIND» — рабочее название. Цены, адрес и часы работы условные.
Статический сайт без сборки, публикуется через GitHub Pages из ветки `main`.
Локально: `python3 -m http.server` → http://localhost:8000
