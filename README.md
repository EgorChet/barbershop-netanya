# GRIND Barbershop — Нетания · концепт сайта

Образцы сайта для барбершопа Димы и Кирилла в Нетании. Четыре версии, каждая по мотивам одного референса:

| # | Версия | Референс |
|---|--------|----------|
| 01 | [`v1-skate/`](v1-skate/) | Thrasher Magazine: панк-зин, огонь, стикеры |
| 02 | [`v2-bold/`](v2-bold/) | TOPGUN, крупнейшая сеть барбершопов в РФ и СНГ: чёрный и красный, Bebas Neue |
| 03 | [`v3-club/`](v3-club/) | OldBoy Barbershop: тёмный джентльменский клуб, золото |
| 04 | [`v4-clean/`](v4-clean/) | Chop-Chop, скандинавский минимализм: светлый, простая запись |

- `/` — экран выбора версии
- `assets/switcher.js` — плавающая панель переключения версий (подключена на каждой странице)
- `assets/img/` — фото мастеров

«GRIND» — рабочее название. Цены, адрес и часы работы условные.

Статический сайт без сборки, публикуется через GitHub Pages из ветки `main`.
Локально: `python3 -m http.server` и открыть http://localhost:8000.
